Sobre o sistema

IMC Calc

versão 2.0 · interface web

O que é

IMC Calc é uma aplicação desenvolvida em Java com o objetivo de realizar o cálculo do Índice de Massa Corporal (IMC), fornecendo ao usuário uma classificação baseada nos padrões de referência estabelecidos pela Organização Mundial da Saúde.

Propósito do projeto

Além da funcionalidade prática, o projeto é uma iniciativa de estudo voltada ao fortalecimento dos fundamentos da linguagem Java e à consolidação de conceitos essenciais do desenvolvimento backend, incluindo:

  • Programação Orientada a Objetos (POO)
  • Estruturas condicionais e de repetição
  • Organização em camadas (entidades, serviços, controller)
  • Manipulação e validação de entrada de dados
  • Encapsulamento e separação de responsabilidades
  • Construção de interface web com Spring Boot e Thymeleaf

Histórico do projeto

Iniciado como uma aplicação de console em Java puro, evoluiu para uma interface web construída com Spring Boot, mantendo a mesma lógica de cálculo e classificação do IMC na camada de serviço.
